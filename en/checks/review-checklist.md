# Owner's review checklist

Everything measurable has already been checked by `checks.py` and the judge. This list is only what needs human judgment. If something here comes up as a rejection three times, turn it into a rule or a check.

## Per piece (finalists)

- [ ] Does the image tell what the content says (the lyrics, the topic, the episode)?
- [ ] Does the emotion match the brief?
- [ ] Does it feel like this channel and no other?
- [ ] Is it different from recent pieces? (If not, there's a repetitive-content risk.)

## Per batch (final cut)

- [ ] The batch's order and pacing work.
- [ ] Thumbnails stand apart from each other in the grid.
- [ ] Nothing rejected this week has come back.

## Every rejection

Write a single sentence with the reason. The agent logs it in `reasons.csv` with `log-rejection`.
