# Piezas aprobadas

Guarda aquí las imágenes o frames que el responsable aprobó. Definen el estilo mejor que cualquier texto.

- Nombre: `si_<escena>_v<version>.png`, por ejemplo `si_olivar-amanecer_v1.png`. Un nombre descriptivo permite citarla desde BIBLIA.md y que el agente sepa qué muestra sin abrirla.
- Cantidad: entre 10 y 30 para empezar. Con 20 a 30 ya se puede entrenar un modelo de estilo propio (LoRA o modelo personalizado).
- Solo piezas que el responsable aprobaría hoy sin tocar.
